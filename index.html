My Chitti & MC Vendor Hub

My Chitti helps customers find local shops, services and technicians. MC Vendor Hub is a separate platform where vendors run billing, POS, CRM and WhatsApp. A dedicated AI agents server handles vendor chat and lets customers book services on WhatsApp. I work across all three.

  • AI agents on a separate server that handle vendor chat and service booking on WhatsApp

  • A separate Meta WhatsApp Business API setup for each vendor
  • FCM push notifications and SMS gateway alerts for users and vendors
  • Payment gateway integrations for secure transactions
  • Server integrations and CI/CD pipelines across environments
